# 文本挖掘智能体需求与范围

## 已确定

- 以实际文本挖掘应用为主，为用户发现议题、理解需求和评价、解释访谈、组织知识、查询证据并形成报告。
- 覆盖主题洞察、需求分析、情感观点、访谈研究、知识发现、证据问答、变化分析及专题研究8类应用。
- Agent根据问题组织分析工具、补充证据和生成成果，用户可检查、修改和迭代。
- 支持其他课程项目复用通用分析能力，领域采集、推荐和模拟交易由对应项目扩展。
- 不设置编码、分词算法、BPE训练和语言模型原理等独立教学演示功能。必要的文本处理、表示和模型调用作为底层实现。
- 当前仅完成功能规划，尚未实现应用代码或界面。

## 第一版范围

见[应用功能清单](FUNCTION_CHECKLIST.md)。优先完成反馈与需求洞察：主要议题、困难诉求、具体对象评价、证据问答、Agent组织分析、报告生成与人工修订。后续扩展访谈解释、群体及阶段比较，或事件与图谱专项。

## 后续细化

- 首个实际任务、输入材料、用户与预期成果。
- 通用分析工具接口、证据定位和人工复核方式。
- 可用模型、数据使用范围、计算预算及部署方式。
- 基线、人工复核集、失败案例及任务效果验收。

单组深入完成一项应用，不要求覆盖全部清单。评价重点为分析价值、证据可靠性和实际任务效果。
